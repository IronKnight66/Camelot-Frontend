## Quick Download Instructions

### Using Pixabay:
1. Visit https://pixabay.com/images/search/parchment%20texture/
2. Find a subtle parchment texture you like
3. Click "Free Download"
4. Download largest size available
5. Save to appropriate folder

### Using 3D Textures:
1. Visit https://3dtextures.me/tag/medieval/
2. Browse medieval stone textures
3. Click on texture you like
4. Download (CC0 license - no attribution needed)
5. Use the diffuse/color map for web

### Using Vecteezy:
1. Visit https://www.vecteezy.com/free-vector/celtic-border
2. Browse free celtic/gothic borders
3. Download SVG format
4. May require free account
